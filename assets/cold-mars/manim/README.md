# Web clip provenance

`closure-temperature.mp4` is the combined render of
`ClosureTemperatureClip` in `geochronology/web_clips.py`.

- `temperature-retention.mp4` uses 0.0–6.8 seconds: temperature varies while
  elapsed time and domain size are fixed.
- `domain-size-retention.mp4` begins at 7.8 seconds, after the replacement
  transform has finished: domain size varies while temperature is fixed.

Both clips are H.264/yuv420p with the MP4 metadata moved to the beginning of
the file. Their poster frames are taken 0.05 seconds after the corresponding
clip starts.
